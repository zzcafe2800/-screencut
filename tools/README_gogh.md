# gogh 自動ドロップくん

便利くんGで分割した画像を、goghのgタイルに自動で貼るWindows用ソフトです。

## 使い方
1. 便利くんGで画像を分割 → ZIPを保存 → 展開する(フォルダ名の `_5x8` がマス数の基準になります)
2. `gogh_start.bat` を起動 → 「フォルダを選ぶ」
3. gogh を編集モードにして、プロジェクター(カード)全体が見える状態にする
4. 「カードの4つの角を指定」で、**カード全体の外側の角**を 左上 → 右上 → 左下 → 右下 の順にクリック
5. 自動で位置を確認し、全画像を先に読み込んで確認したうえで、確認画面が出ます
   - 最初は「完成予想」(画像を貼った後の見え方) を表示。「今の画面を見る」で切り替え
   - g が逆さまのマスは水色の ↻。その画像は自動で180度回転して貼ります
   - 「画質」で画像を小さくすると、ゲームの読み込みが速くなります (作業用フォルダ `…_gogh` に作成。元の画像はそのまま)
   - 明るいときは g を画像で探して位置を補正(緑)
   - 夜で暗い・g が見えないときは、4つの角を 5×8 に等分して計算(オレンジ)
6. 「この配置でOK」→「テスト」→「全部開始」
   - エクスプローラーは自動で開き、ファイルが隠れていてもスクロールして名前を見つけてからつかみます
   - 貼るたびにゲームの読み込みが終わるのを待ってから次へ進みます
7. 止めたいときは **Esc キー**

## 安全性
- Python標準機能のみ・外部ライブラリなし。管理者権限なし。
- 通信は `gogh_start.bat` の自動アップデート(このリポジトリの `gogh_autodrop_gui.py` を取得)だけです。止めたいときは、同じフォルダに `no_update.txt` という空のファイルを置いてください。
- ゲームのメモリやファイルには触らず、マウスを動かすだけです。
- g の位置確認と読み込み待ちのために、指定範囲の画面だけを撮影します。画像は送信しません。
- ソースは `tools/gogh_autodrop_gui.py` 1ファイルで、誰でも中身を確認できます。
- exeはGitHub Actionsが公開ソースから自動で作ります(Actions タブ → Build gogh-autodrop → Artifacts)。
  同梱の `sha256.txt` でダウンロードの改ざんがないか確認できます。
- コード署名をしていないため、Windowsに「不明な発行元」と表示されることがあります。
  不安な人は Python をインストールして `python gogh_autodrop_gui.py` で直接実行できます。

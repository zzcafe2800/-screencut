# gogh 自動ドロップくん

便利くんGで分割した画像を、goghのgタイルに自動で貼るWindows用ソフトです。

## 使い方
1. 便利くんGで画像を分割 → ZIPを保存 → 展開する
2. `gogh-autodrop.exe` を起動
3. 「フォルダを選ぶ」で展開したフォルダを選ぶ(フォルダ名から縦横の数が自動で入ります)
4. goghを編集モードにして、タイルが全部見える状態にする(カメラは動かさない)
5. エクスプローラーはソフトが自動で開き、ファイルも自動で見つけます(位置の指定は不要)
6. 「gのタイル4隅を指定」で、画面をクリックして位置を教える(設定は保存されます)
7. 「テスト」で位置を確認 → 「開始」
8. 止めたいときは **Esc キー**

## 安全性
- Python標準機能のみ・外部ライブラリなし。管理者権限なし。
- 通信は `gogh_start.bat` の自動アップデート(このリポジトリの `gogh_autodrop_gui.py` を取得)だけです。止めたいときは、同じフォルダに `no_update.txt` という空のファイルを置いてください。
- ゲームのメモリやファイルには触らず、マウスを動かすだけです。
- ソースは `tools/gogh_autodrop_gui.py` 1ファイルで、誰でも中身を確認できます。
- exeはGitHub Actionsが公開ソースから自動で作ります(Actions タブ → Build gogh-autodrop → Artifacts)。
  同梱の `sha256.txt` でダウンロードの改ざんがないか確認できます。
- コード署名をしていないため、Windowsに「不明な発行元」と表示されることがあります。
  不安な人は Python をインストールして `python gogh_autodrop_gui.py` で直接実行できます。
